# Go Challenges & Practice

Welcome to my **Go Challenges** repository! 

This is a personal collection of coding challenges, algorithms, and practice problems written in [Go (Golang)](https://golang.org/ ). I created this repository to track my progress, practice problem solving, and solidify my understanding of Go's core concepts. 

Whether you are a beginner looking for examples or an experienced developer brushing up on the basics, I hope you find these solutions helpful!

##  Repository Structure

To make navigation easy, the challenges are categorized by topic:

| Category | Description |
| :--- | :--- |
| 🧮 **`math/`** | Number manipulation, arithmetic operations, and recursion (e.g., factorials, powers). |
| 🔤 **`strings/`** | String formatting, rune manipulation, reversing, and splitting. |
| 📚 **`arrays_slices/`** | Array filtering, slice manipulation, and sorting algorithms. |
| 🔗 **`structs_pointers/`** | Memory management, pointers, and custom data structures. |
| 🧠 **`logic_misc/`** | General problem-solving, date calculations, and miscellaneous logic. |
| 💻 **`scripts/`** | Handy bash/shell scripts used for file manipulation and testing. |

## How to Run the Code

You can run any of the Go files directly from your terminal. Make sure you have [Go installed](https://go.dev/doc/install ) on your machine.

1. **Clone the repository:**
   
```bash
git clone https://github.com/muhammad-owais-javed/go-challenges.git
cd go-challenges
```

2. **Run a specific challenge:**

Navigate to the folder and use the go run command. For example:
    

    go run strings/strreverse.go

## Goals of this Repository

- **Master Go Syntax:** Get comfortable with Go's unique syntax, types, and idioms.
- **Algorithmic Thinking:** Practice breaking down problems and solving them efficiently.
- **Reference Material:** Serve as a quick lookup for common operations (like string manipulation or slice filtering ) in future projects.
